# 📁 Smart File Organizer

A simple Python CLI tool that automatically organizes files into folders based on their file type.

## ✨ Features

- Images, documents, videos, audio, and archives are grouped automatically
- Unknown file types go into `Others`
- Avoids overwriting files with duplicate names
- Uses only Python's standard library
- Runs locally — no API key required

## ▶️ Run

```bash
python file_organizer.py
```

Enter the path of the folder you want to organize.

## 🛡️ Safety

The script only processes files directly inside the selected folder. Hidden files are skipped.
